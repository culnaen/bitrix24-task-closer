# Bitrix24 Task Closer

Userscript для Bitrix24: добавляет к карточкам задач одиночное и групповое
завершение, записывает затраченное время и добавляет результат через REST API.

## Использование

Для одной заявки нажмите **«Завершить…»** прямо в её карточке. В открывшемся
окне укажите время и комментарий, затем подтвердите завершение.

Для нескольких заявок:

1. Отметьте **«Выбрать»** в карточках нужных заявок.
2. В появившейся снизу панели нажмите **«Завершить…»**.
3. Укажите общие время и комментарий. Они будут записаны в каждую выбранную
   заявку, после чего заявки будут завершены по очереди.

Если часть групповой операции завершилась ошибкой, диалог покажет количество
успешных и проблемных заявок. Не повторяйте частично выполненную операцию вслепую:
сначала проверьте отмеченные номера заявок в Bitrix24.

## Установка

1. Установьте расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Создайте в нём новый userscript и замените его содержимое файлом
   `bitrix24-close-task.user.js` из этого репозитория.
3. Откройте меню расширения Tampermonkey на странице задач и выберите
   **«Настроить Bitrix24 Task Closer»**.
4. Укажите данные вебхука и сохраните настройки.
5. Обновите страницу задач по адресу
   `https://<ваш-портал>/company/personal/user/<ID>/tasks/`.

## Настройка через Tampermonkey

Параметры сохраняются в изолированном хранилище Tampermonkey через `GM_setValue`;
в файл userscript секрет вебхука не записывается. Пункт
**«Настроить Bitrix24 Task Closer»** доступен в меню Tampermonkey на странице задач.

- `WEBHOOK_USER_ID` — ID пользователя, от имени которого создан входящий вебхук.
- `WEBHOOK_CODE` — код входящего вебхука Bitrix24. Это секрет: не публикуйте его.
- `ELAPSED_SECONDS` — время по умолчанию; в окне настроек вводится в минутах.
- `COMPLETION_COMMENT` — текст результата задачи; по умолчанию `Решено.`.
- `COMMENT_MODE` — `auto` по умолчанию; также доступны `chat` и `legacy`.


Создать вебхук можно в Bitrix24: **Разработчикам → Другое → Входящий вебхук**.
Для работы скрипта у вебхука должны быть права на задачи и чат. Метаданные
userscript уже разрешают запуск на HTTPS-порталах Bitrix24; если у вас другой путь
к списку задач, скорректируйте строку `@match`.

## Публикация

Перед отправкой на GitHub убедитесь, что в `DEFAULT_CONFIG.WEBHOOK_CODE` остаётся
значение-заглушка. Секрет вебхука хранится только в настройках Tampermonkey.
