# Bitrix24 Task Closer

Userscript для списка задач Bitrix24: завершает выбранные задачи отдельной
кнопкой в нижней панели, записывает затраченное время и результат через REST API.

## Использование

Для одной или нескольких задач:

1. Отметьте штатные чек-боксы в строках нужных задач (можно выбрать все на странице).
2. В появившейся снизу панели нажмите **«Завершить…»** — не штатную кнопку
   массового изменения Bitrix24.
3. Укажите время и результат работы. Для нескольких задач они будут одинаковыми;
   задачи завершатся по очереди.

Если часть групповой операции завершилась ошибкой, диалог покажет количество
успешных и проблемных заявок. Не повторяйте частично выполненную операцию вслепую:
сначала проверьте отмеченные номера заявок в Bitrix24.

## Установка в Tampermonkey

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Нажмите **[«Установить userscript»](https://culnaen.github.io/bitrix24-task-closer/bitrix24-close-task.user.js)** и подтвердите установку в Tampermonkey.
3. Откройте меню расширения Tampermonkey на странице задач и выберите
   **«Настроить Bitrix24 Task Closer»**.
4. Укажите данные вебхука и сохраните настройки.
5. Откройте вкладку **«Список»** по адресу
   `https://<ваш-портал>/company/personal/user/<ID>/tasks/?F_STATE=sV80`.

Нижняя панель скрипта появляется только на этой странице при выборе задач
(не во вкладке «Сроки») и только в верхнем фрейме. Повторный запуск в том же
документе блокируется; изменения интерфейса Bitrix24 объединяются в одно
обновление на кадр.

## Настройка через Tampermonkey

Параметры сохраняются в изолированном хранилище Tampermonkey через `GM_setValue`;
в файл userscript секрет вебхука не записывается. Пункт
**«Настроить Bitrix24 Task Closer»** открывает форму настроек в меню Tampermonkey
на странице задач. Кнопка **«Сбросить»** восстанавливает значения по умолчанию.

- `WEBHOOK_USER_ID` — ID пользователя, от имени которого создан входящий вебхук.
- `WEBHOOK_CODE` — код входящего вебхука Bitrix24. Это секрет: не публикуйте его.
- `ELAPSED_SECONDS` — время по умолчанию; в окне настроек вводится в минутах.
- `COMPLETION_COMMENT` — текст результата задачи; по умолчанию `Решено.`.

Создать вебхук можно в Bitrix24: **Разработчикам → Другое → Входящий вебхук**.
В его правах нужны **оба** scope: `task` для учёта времени и завершения
и `tasks` для REST 3.0 (проверка доступа и запись результата). Если старый
вебхук не содержит `tasks`, добавьте это право в настройках вебхука или создайте
новый вебхук с обоими правами и обновите код в Tampermonkey. Отсутствие `tasks`
теперь обнаруживается до записи времени. Права на чат (`im`) не нужны.

Скрипт записывает результат непосредственно в задачу, не отправляя отдельное
сообщение в чат. Метаданные userscript уже разрешают запуск на HTTPS-порталах
Bitrix24; если у вас другой путь к списку задач, скорректируйте строку `@match`.

## Публикация

Перед отправкой на GitHub убедитесь, что в `DEFAULT_CONFIG.WEBHOOK_CODE` остаётся
значение-заглушка. Секрет вебхука хранится только в настройках Tampermonkey.
